# Security Policy

TALARIA v0.1 is an experimental local-first project. It is not hardened for multi-user or internet-facing deployment. Run it only on trusted machines and repositories you are authorized to assess. The API has no authentication or authorization layer; keep it bound to localhost. Reports and the SQLite database can contain sensitive source excerpts.

For a vulnerability report, do not open a public issue containing exploit details or secrets. Contact the maintainers privately through the repository's security reporting mechanism once configured.
