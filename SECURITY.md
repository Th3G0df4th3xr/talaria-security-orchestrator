# Security Policy

TALARIA is an experimental local-first project. It now has bearer authentication, organization membership, basic role checks, tenant-scoped core API queries, and refresh-session controls. It is not hardened for internet-facing deployment; keep it bound to localhost. Reports and the SQLite database can contain sensitive source excerpts.

For a vulnerability report, do not open a public issue containing exploit details or secrets. Contact the maintainers privately through the repository's security reporting mechanism once configured.
